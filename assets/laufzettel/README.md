# Graphics of the schedule designer

Drawn for this project (flat style, free to use and change): cocktail, pizza, spaghetti (line art),
wine glass, chef hat, fork and spoon, sparkle, rays, dashed arrow and the icons.
The pot, spatula, carrot, cake and the two leaves are the existing files in `assets/`.

To add a graphic: put the file here, add it to `BUILTIN_GRAPHICS` in `src/schedule_design.rs` and
to the `graphics!` list in `src/side/details/run_schedule/builtin.rs` (a test checks both).
